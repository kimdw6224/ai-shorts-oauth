개인정보처리방침

시행일: 2026년 9월 30일

AI Shorts Local(이하 "도구")은 YouTube 채널 ㄱㄷㅇ 운영자가 자기 채널을 관리하려고 쓰는 개인용 도구입니다. 이 방침은 도구가 Google 사용자 데이터를 어떻게 다루는지 설명합니다.

접근하는 데이터

  • youtube.readonly: 운영자 채널의 채널 ID·이름, 업로드한 영상의 ID·제목·설명·공개 상태·처리 상태·카테고리·길이
  • youtube.upload: 운영자가 승인한 영상 파일과 제목·설명을 운영자 채널에 업로드

사용 목적

중복 업로드를 막고, 게시한 영상이 의도한 설정으로 올라갔는지 확인하고, 운영자가 승인한 영상을 올리는 데만 사용합니다. 광고, 프로필 분석, 머신러닝 학습에는 사용하지 않습니다.

저장

OAuth 토큰은 운영자 컴퓨터의 접근이 제한된 로컬 파일에만 저장합니다. 확인 결과는 영상 ID·상태 같은 필요한 항목만 운영자 컴퓨터에 JSON 파일로 남기며, API 응답 원문과 토큰은 기록하지 않습니다.

공유

Google 사용자 데이터를 제3자에게 판매하거나 공유하지 않습니다. 데이터는 Google API와 운영자 컴퓨터 사이에서만 오갑니다.

Google API 서비스 사용자 데이터 정책

도구가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

권한 철회와 삭제

Google 계정 권한 페이지에서 언제든 도구의 접근을 철회할 수 있습니다. 운영자 컴퓨터의 토큰 파일과 확인 결과 파일은 운영자가 직접 삭제합니다. 삭제 요청은 아래 연락처로 보내 주세요.
