개인정보처리방침

시행일: 2026년 9월 30일

AI Shorts Local(이하 "도구")은 YouTube 채널 ㄱㄷㅇ 운영자가 자기 채널을 관리하려고 쓰는 개인용 도구입니다. 도구는 YouTube API Services를 사용하며, 이 방침은 도구가 YouTube API Services와 Google 사용자 데이터를 어떻게 다루는지 설명합니다. 도구를 사용하면 이 방침과 Google 개인정보처리방침에 동의하게 됩니다.

접근·수집하는 데이터

  • youtube.readonly: 운영자 채널의 채널 ID·이름, 업로드한 영상의 ID·제목·설명·공개 상태·처리 상태·카테고리·아동용 여부·길이
  • youtube.upload: 운영자가 승인한 영상 파일과 제목·설명을 운영자 채널에 업로드
  • OAuth refresh token: 매 실행마다 새 접근 토큰을 받는 데만 사용

사용 목적

중복 업로드를 막고, 게시한 영상이 의도한 설정으로 올라갔는지 확인하고, 운영자가 승인한 영상을 올리는 데만 사용합니다. 광고, 프로필 분석, 머신러닝 학습에는 사용하지 않습니다.

저장과 보관 기간

OAuth 토큰은 운영자 컴퓨터의 접근이 제한된 로컬 파일에만 저장합니다. 확인 결과는 영상 ID·상태 같은 필요한 항목만 운영자 컴퓨터에 JSON 파일로 남기며, API 응답 원문과 토큰은 기록하지 않습니다. 확인 결과 파일은 만든 날로부터 30일이 지나면 도구가 자동으로 삭제합니다.

공유

Google 사용자 데이터와 YouTube API 데이터를 제3자에게 판매하거나 공유하지 않습니다. 데이터는 Google API와 운영자 컴퓨터 사이에서만 오가며, 외부 서버나 다른 앱으로 보내지 않습니다.

쿠키와 광고

도구는 명령줄 프로그램이라 쿠키나 브라우저 저장소를 쓰지 않고, 광고나 제3자 콘텐츠를 표시하지 않습니다. 이 안내 페이지도 쿠키를 설정하지 않습니다. 페이지를 제공하는 GitHub Pages는 GitHub 개인정보처리방침에 따라 접속 기록을 남길 수 있습니다.

권한 철회와 삭제

  • 도구에서 uv run python jobs/youtube_check.py revoke를 실행하면 Google에 토큰 폐기를 즉시 요청하고, 저장된 토큰과 YouTube API로 받은 확인 결과 파일을 바로 삭제합니다.
  • Google 보안 설정에서도 언제든 도구의 접근을 철회할 수 있습니다. 도구는 매일 한 번 토큰이 유효한지 확인하며, 철회된 것을 확인하면 저장된 토큰과 확인 결과 파일을 즉시 삭제합니다. 운영자 컴퓨터가 꺼져 있던 기간이 있어도 켜진 뒤 첫 확인에서 삭제하며, 어떤 경우든 30일 안에 삭제를 마칩니다.
