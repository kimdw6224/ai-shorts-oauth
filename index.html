AI Shorts Local

AI Shorts Local은 YouTube 채널 ㄱㄷㅇ(@boredbox_918) 운영자가 자기 채널의 영상을 관리하려고 만든 개인용 도구입니다. 운영자의 컴퓨터에서 명령줄로만 실행되며 다른 사람에게 제공하거나 판매하지 않습니다.

이 도구는 YouTube API Services를 사용합니다. 사용하기 전에 개인정보처리방침과 이용약관을 확인해 주세요. 도구를 사용하면 YouTube 서비스 약관에도 동의하게 됩니다.

하는 일

  • 운영자 채널의 업로드 목록을 읽어 같은 영상이 이미 올라가 있는지 확인합니다.
  • 게시한 영상의 공개 상태, 처리 상태, 제목, 설명, 카테고리를 확인합니다.
  • 운영자가 승인한 영상을 운영자 채널에 업로드합니다.

Google 계정 권한은 YouTube 업로드(youtube.upload)와 YouTube 읽기(youtube.readonly) 두 가지만 요청합니다.

권한 철회

도구에서 youtube_check.py revoke를 실행하거나 Google 보안 설정에서 언제든 접근을 철회할 수 있습니다.
